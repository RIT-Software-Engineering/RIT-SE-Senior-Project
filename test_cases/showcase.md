## Featured Projects

1. All projects with the featured tag will show up on the landing page in the topmost carousel. Under the carousel lists the current project out of the total number of projects. The user should be able to use the arrows to navigate through all featured projects, and the current project number should update accordingly.

2. If the user clicks on a featured project, then a modal with more information on the project should display.

3. If the user is on the very last slide and clicks on the right arrow, then the first slide should display with the pagination updating to 1 of total.

4. If the user logs in as an admin, navigates to the "Admin" tab, opens the "Archive" accordion, and changes the "featured" tag on a project, then the total number of featured projects listed under the carousel should update.

5. If the user shortens the screen to shorter than 1200px, only one featured project should display.

6. If the user shortens the screen to shorter than 1200px, the current project number and total number of projects should remain unchanged. This must be true when the user widens the screen again.

7. Some featured projects will have an award associated with it. If a featured project has one award, then there should be a diagonal sash on the top right corner of the card in the award's configured color. If it has two awards, a sash for each award should display on both top corners of the card. If the user navigates to the "Admin" tab, opens the "Archive" accordion, and updates the award tags on a project, then the sashes should update on the carousel.

## Description

1. Under the featured project carousel is a black area with a description of the course as well as a button for submitting a project proposal. If the screen width is larger than 768px, this should display as a left and right content area.

2. When the user clicks on the "Sponsor a Project" button, they should be taken to the project proposal form.

3. If the user shortens the screen width to shorter than 768px, the left and right content areas should stack on top of each other with the text adjusting to the screen width.

## Current Projects

1. When the user scrolls down on the page, there will be a section titled "What Our Students Are Working On" with projects that are currently ongoing. When this happens, the initial animation of the cards gliding in should play.

2. If the user clicks on a current project, then a modal with more information on the project should display.

3. If the user shortens the screen to shorter than 1200px, only one current project should display.

4. If the user shortens the screen to shorter than 1200px, the current project number and total number of projects should update to the current project number out of the total number of projects. When the user widens their screen again, it should return to being the current slide number out of the total number of slides.

5. If the user navigates to the last slide with the total number of current projects being indivisible by three, only the last one or two projects should display rather than the carousel completely wrapping around.

## Header

1. When the screen width is wider than 768px, the header should be a black bar. The leftmost side should contain the navigation buttons for Home, All Projects, and Sponsor A Project. The rightmost side should contain the button for Sign In.

2. Clicking on the Home button should simply keep the user on the landing page.

3. Clicking on the All Projects button should take the user to the Browse All Projects page.

4. Clicking on the Sponsor A Project button should take the user to the info page titled "Become a Project Sponsor".

5. Clicking on Sign In should open a modal for the user to sign in.

6. If the user shortens the screen to shorter than 768px, the black bar should disappear and a hamburger icon should display on the top right corner. Clicking the icon should open a sidebar menu containing Home, Projects, Sponsor a Project, Profile, and Sign In.
