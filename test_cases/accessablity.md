# Student Accessibility

## Current Accessibility Problems

### Dashboard Action Information

Action details such as title, dates, project, and submission status are not consistently available in a screen-reader-friendly structure.

### Student Name Keyboard Access

Some student names are clickable table cells and cannot be reliably reached or opened with the keyboard.

### Expanded Student List Navigation

Keyboard navigation may skip or incorrectly order items in expanded student lists.

### Email-All Accessible Name

The email-all icon does not provide a clear accessible name to Windows Narrator.

### Student Details Modal Focus

Focus may remain on the background page when the modal opens and may not return to the original student name when it closes.

### Student Details Field Labels

The Additional Info, AI Summary, and Custom Prompt fields may be announced without clear labels.

### Clickable Profile Elements

Some clickable profile elements lack keyboard support, accessible names, and button or link semantics.
